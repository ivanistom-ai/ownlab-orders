# Своя почта для входа (SMTP)

Встроенная почта Supabase отправляет письма только участникам проекта и не больше нескольких в час.
Своя почта нужна, чтобы работали подтверждение почты при регистрации и восстановление пароля.

## 1. Что нужно (делает владелец)
1. **Домен** для адреса отправителя, например `ownlab.ru` (≈200–900 ₽/год у reg.ru, nic.ru, timeweb).
2. **Почтовый сервис в РФ** — любой из вариантов:

| Сервис | Сервер | Порт | Логин |
|---|---|---|---|
| Яндекс 360 для бизнеса | `smtp.yandex.ru` | 465 (SSL) | адрес ящика + **пароль приложения** |
| VK WorkSpace (Mail.ru для бизнеса) | `smtp.mail.ru` | 465 (SSL) | адрес ящика + пароль для внешних приложений |
| Unisender Go (транзакционные письма) | `smtp.go1.unisender.ru` | 587 | из личного кабинета |

3. Ящик отправителя, например `noreply@ownlab.ru`, и записи **SPF и DKIM** в DNS домена — сервис показывает их при подключении домена. Без них письма будут попадать в спам.

## 2. Подключить в Supabase
**Authentication → Emails → SMTP Settings → Enable custom SMTP**:
- Sender email: `noreply@ownlab.ru`, Sender name: `OWNLAB`
- Host, Port, Username, Password — из таблицы выше. Пароль вводите сами, никому его не пересылайте.

Затем **Authentication → Rate Limits**: «Rate limit for sending emails» — поставить 30–60 в час.

## 3. Включить подтверждение почты обратно
**Authentication → Sign In / Providers → Email → Confirm email** — включить. Сайт уже умеет: после регистрации просит подтвердить почту, а приглашение применяется после первого входа.

## 4. Письма на русском
**Authentication → Emails → Templates** — вставить тексты ниже.

**Confirm signup** — тема: `Подтвердите почту для OWNLAB`
```html
<h2>Подтвердите почту</h2>
<p>Вы регистрируетесь в системе заказов OWN Digital Laboratory.</p>
<p><a href="{{ .ConfirmationURL }}">Подтвердить почту</a></p>
<p>Если вы не регистрировались — просто проигнорируйте это письмо.</p>
```

**Reset Password** — тема: `Восстановление пароля OWNLAB`
```html
<h2>Новый пароль</h2>
<p>Чтобы задать новый пароль, нажмите на ссылку:</p>
<p><a href="{{ .ConfirmationURL }}">Задать новый пароль</a></p>
<p>Если вы не запрашивали смену пароля — проигнорируйте письмо, пароль останется прежним.</p>
```

**Change Email Address** — тема: `Подтвердите новую почту OWNLAB`
```html
<h2>Смена почты</h2>
<p>Подтвердите, что новая почта {{ .NewEmail }} принадлежит вам:</p>
<p><a href="{{ .ConfirmationURL }}">Подтвердить</a></p>
```

## 5. Проверка
1. «Забыли пароль?» на странице входа → письмо должно прийти за минуту.
2. Пригласите тестового сотрудника на свою вторую почту и зарегистрируйтесь по ссылке.
