# Подключение сервера (Supabase, демо)

Без подключения сайт работает как демо: данные живут только в открытой вкладке.
После подключения появляются вход, регистрация по приглашениям, 5 ролей и общие для всех заказы, чат и файлы.

> Supabase — зарубежный сервис. Подходит для проверки с **вымышленными** данными.
> Реальных пациентов вносить только после переезда на сервер в РФ (152-ФЗ).

## 1. Создать проект (делает владелец аккаунта)
1. Зарегистрироваться на https://supabase.com → **New project**.
2. Name: `ownlab-orders`, Region: `Central EU (Frankfurt)`. Пароль базы придумать и сохранить у себя — он сайту не нужен.

## 2. Создать таблицы и права
**SQL Editor → New query** → вставить весь файл [`schema.sql`](schema.sql) → **Run**. Должно появиться `Success. No rows returned`.

## 3. Настроить вход
- **Authentication → Sign In / Providers → Email**: выключить **Confirm email** → Save.
  Встроенная почта Supabase отправляет письма только участникам проекта, поэтому без своего SMTP подтверждение почты не дойдёт до сотрудников. Для боевой версии подключается свой почтовый сервер (Authentication → Emails → SMTP), и подтверждение включается обратно.
- **Authentication → URL Configuration**: Site URL — `https://ivanistom-ai.github.io/ownlab-orders/`, в Redirect URLs добавить тот же адрес.

## 4. Подключить сайт
**Project Settings → API Keys**: скопировать **Project URL** и **Publishable key** (или `anon` key) в [`../config.js`](../config.js).
Эти два значения публичные. **Secret / service_role key никуда не вставлять и никому не пересылать.**

## 5. Первый вход
Открыть сайт → «Первичная настройка: зарегистрировать собственника». Это работает один раз.
Дальше: **Пользователи → Пригласить** → ссылка копируется → отправить сотруднику.

## Роли
| | Собственник | Админ лаборатории | Техник | Админ клиники | Врач |
|---|---|---|---|---|---|
| Видит заказы | все | все | назначенные | своей клиники | свои |
| Создаёт заказы | ✓ | ✓ | — | ✓ | ✓ |
| Меняет этапы | ✓ | ✓ | ✓ | согласование и получение | согласование и получение |
| Цены | ✓ | ✓ | — | видит | — |
| Отчёты | ✓ | ✓ | — | своей клиники | — |
| Накладные, счета-фактуры | ✓ | ✓ | — | — | — |
| Приглашает | всех, кроме собственника | техников, клиники, врачей | — | врачей своей клиники | — |
| Реквизиты, удаление заказов | ✓ | — | — | — | — |

Права проверяет сервер (Row Level Security), а не только интерфейс.

## Ограничения бесплатного тарифа
- Файл до 50 МБ, хранилище 1 ГБ, база 500 МБ.
- Проект засыпает после 7 дней без активности — просыпается при входе в панель Supabase.
