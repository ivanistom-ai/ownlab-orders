# OWN Digital Laboratory — Система заказ-нарядов

Веб-приложение для управления заказ-нарядами зуботехнической лаборатории OWNLAB.

## Структура

| Путь | Что это |
|---|---|
| `index.html` | Основное приложение: заказы, этапы, техники, комментарии (светлая тема) |
| `apps/order-system-v1.html` | Ранняя расширенная версия системы заказов |
| `apps/orders-table.html` | Таблица нарядов / трекер лаборатории |
| `apps/order-checklist.html` | Стандарт работы техника (чек-лист заказа) |
| `apps/ai-cad.html` | OWNLAB AI — Dental CAD (прототип) |
| `apps/splint-v2.html`, `apps/splint-service.html` | OWNLAB SPLINT AI — окклюзионные шины (прототипы) |
| `src/OwnLabOrders.jsx` | React-версия системы заказов |
| `docs/` | Формы F01–F03, стандарт работы техника, инструкция |

## Запуск

Сейчас это статические страницы — откройте `index.html` в браузере.
Данные заказов демонстрационные и хранятся в памяти страницы (после перезагрузки сбрасываются).

## Дальше

Для рабочего приложения нужен сервер с базой данных и авторизацией (врачи, техники, администратор).
